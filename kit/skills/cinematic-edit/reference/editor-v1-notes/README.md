# editor-v1 reference notes (read-only)
Copied from the NextPhase Editor V1 kit (free to use, not to resell). These are the frame-by-frame measurements of three documentary-style
reels and the device specs of the HTML/GSAP version of the style. Use them as TARGET NUMBERS (shot lengths, click levels, caption tiers,
device timings) when building documentary-mode edits. The code in them (HyperFrames `Comp`, `ev1_*` calls) does not exist in cinematic-edit:
the same devices are `devices.py` entries here. Where `devices.md` and `edl/` disagree, `edl/` wins.
